# Погода: справочник

Исходные данные для темы погоды: источники данных, коды WMO, варианты
ответа-«догадки» при недоступности API и советы по одежде.

## Источник данных

### Open-Meteo
- Бесплатный API без ключа.
- Геокодинг: `https://geocoding-api.open-meteo.com/v1/search?name=<город>&count=1&language=ru&format=json`.
- Прогноз: `https://api.open-meteo.com/v1/forecast?latitude=..&longitude=..&current=temperature_2m,apparent_temperature,weather_code,wind_speed_10m&timezone=auto`.

### Формат ответа
- «Погода в Москве: +5 °C (ощущается +2), облачно, ветер 3 м/с.»

## Коды WMO (соответствие описанию)

| Код | Описание |
|---|---|
| 0 | ясно |
| 1 | преимущественно ясно |
| 2 | переменная облачность |
| 3 | пасмурно |
| 45, 48 | туман |
| 51, 53, 55 | морось |
| 56, 57 | ледяная морось |
| 61, 63, 65 | дождь |
| 66, 67 | ледяной дождь |
| 71, 73, 75 | снег |
| 77 | снежная крупа |
| 80, 81, 82 | ливень |
| 85, 86 | снегопад |
| 95 | гроза |
| 96, 99 | гроза с градом |

## Ответ-догадка при сбое API

Если не удалось получить данные, бот выбирает один из вариантов и обязательно
помечает, что это предположение:

- «Похоже, сегодня солнечно.»
- «Судя по всему, облачно.»
- «Кажется, собирается дождь.»
- «Вероятно, прохладно и ветрено.»
- «Похоже на снег.»
- «Возможно, туман.»
- «Скорее всего, тепло и ясно.»

Пометка: «⚠ Это догадка: актуальные данные получить не удалось.»

## Город не найден

Если геокодинг не нашёл населённый пункт, бот не угадывает, а переспрашивает:
«Не нашёл такой город. Уточните название, пожалуйста.»

## Советы по одежде

### Что надеть
- Холодно (ниже 0 °C): тёплый пуховик, шапка, перчатки, шарф.
- Прохладно (0…+10 °C): куртка, свитер, закрытая обувь.
- Комфортно (+10…+20 °C): лёгкая куртка или кардиган.
- Тепло (выше +20 °C): лёгкая одежда, головной убор, солнцезащитный крем.

### Нужен ли зонт
- При дожде, ливне и мороси — зонт или дождевик.
- При облачности без осадков — зонт не обязателен.
- Летом в жару лучше головной убор и вода.

### Погода и сезон
- Зима: холодно, снег, короткий световой день.
- Весна: переменчиво, возможны дожди и заморозки.
- Лето: тепло и жарко, максимум солнца.
- Осень: прохладно, дожди, ветер.
